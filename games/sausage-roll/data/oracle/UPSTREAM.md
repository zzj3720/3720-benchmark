# Full-game replay provenance

`all.dem` comes from
[`jbzdarkid/SSRDecompile`](https://github.com/jbzdarkid/SSRDecompile), a public
Apache-2.0 TAS tool and complete Stephen's Sausage Roll playthrough.

- pinned commit: `d4237b7fa82e55c7c7eb64e7fc3f0ab7f5ad74b1`
- upstream path: `App/all.dem`
- coverage: all 86 puzzles, overworld setup for the late puzzles, and final
  cleanup
- raw inputs: 16,567 lines
- normalized inputs: 16,361 directions after removing each recorded undo and
  the direction it reverses

The replay is development-only oracle data. It is never packaged into the
Agent environment.

`segments.tar.gz` is a mechanically generated differential-testing fixture. It
contains the stable original-engine entry state and puzzle-only direction
sequence for each of the same 86 levels, plus the stable player/sausage state
after every non-final puzzle input. The final input exits the puzzle and
therefore has no in-puzzle checkpoint. The 86 sequences contain 11,769
directions and 11,683 checkpoints in total. The entry states and checkpoints
were generated by replaying the TAS against the locally owned build recorded
in `../campaign/source.json`.
