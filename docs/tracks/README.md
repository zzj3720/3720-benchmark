# Benchmark Tracks

Tracks are optional curated views over the shared Harbor task bank. They are not
a closed taxonomy and no track has special status at the repository root.

Each track may define:

- the capability or workflow it measures;
- evidence required to accept a case;
- controls needed to isolate that capability;
- track-specific metrics and aggregation;
- task membership for its published dataset.

Current notes:

- [Async orchestration](async-orchestration.md): multitasking, task
  interleaving, and asynchronous collaboration.

Add other tracks only when their scope and acceptance criteria are concrete.
